Chiaki 掌机版 · TrimUI Brick Pro 专用
============================================

一、安装
--------------------------------------------
把本压缩包里的 Apps/Chiaki 整个文件夹放到 SD 卡根目录的 Apps 下，
最终路径是：/mnt/SDCARD/Apps/Chiaki/chiaki_brick
然后在掌机主菜单里就能看到 Chiaki 图标。


二、第一次使用（在家、和 PS5 同一个路由器）
--------------------------------------------
1. 掌机连上 WiFi
2. 主菜单 → Apps → Chiaki
3. 等几秒，会自动搜到你的 PS5，选中按 B 连接
   （没搜到就按 Y 手动添加，输入 PS5 的局域网 IP）
4. PS5 会要求配对：电视上显示 8 位数字 → 掌机自动跳到配对界面
   → 方向键选数字，B 输入，A 删除，选「确定」
5. 配对成功后密钥自动保存，以后直接连


三、不在家时串流（公网）
--------------------------------------------
PS5 远程游玩用的是 UDP 端口，必须在家里的路由器上做端口转发，
指到 PS5 的内网 IP（例如 192.168.50.116）：

    UDP 9295  → PS5        （会话/控制）
    UDP 9296  → PS5        （视频流，最重要）
    UDP 9297  → PS5        （视频流备用）
    UDP 9302  → PS5        （发现 + 待机唤醒）
    TCP 9295  → PS5        （会话/控制，建议一起映射）

注意：只映射 TCP 不够，视频走 UDP，UDP 不通就只能连上但没画面。

强烈建议配一个 DDNS 域名（例如 xxx.asuscomm.com / xxx.ddns.net），
添加主机时直接填域名，家里公网 IP 变了也不用改。

如果家里是「大内网 / CGNAT」（光猫拿到的不是公网 IP），
端口映射无效，这种情况只能走 PSN 远程（本版本未实现）。


四、PSN ID（可选，多数情况留空）
--------------------------------------------
个别 PS5 固件在配对新账号时会校验 PSN Account ID，
格式是 8 字节数据的 base64 字符串（12 个字符左右，含 + / =）。
添加主机时用键盘上的「下一项」按钮（或 R1）切到「PSN ID」输入行填写即可。
不确定就先留空——留空能连上就不用管它。


五、按键说明（按掌机丝印）
--------------------------------------------
主界面：
    B        连接选中的主机
    Y        添加主机（弹出软键盘，输入 IP 或域名）
    X        删除主机（需再按一次确认）
    L2       修改选中主机（改名字 / 地址 / PSN ID，不用重新配对）
    L1       唤醒主机（发 WOL 包，待机的主机会开机）
    R1       设置：分辨率 / 帧率 / 码率 / 编码 / 震动
    SELECT   按键映射（可把任意按键改成别的功能）
    A        退出程序

串流中：
    L1+R1+L3+R3   呼出串流菜单（继续 / 返回列表 / 断开 / 震动测试）
    单击 START     = 触摸板
    长按 START     = OPTIONS
    震动           跟着游戏自动触发，菜单里的「震动测试」可单独验证马达

添加主机界面：
    三个输入项：名称 / 地址 / PSN ID，用「上一项 / 下一项」按钮切换
    （L1 / R1 也能切）
    方向键移动光标，按住不放可以快速连发
    B 输入，A 删除一个字符，START 返回
    SHIFT 切大小写，+ / = 用来拼 base64，PS5/PS4 切类型
    地址填好直接按「确定」就连，PSN ID 留空即可

震动强度在 R1 设置里调，五档：关闭 / 25% / 50% / 75% / 100%，默认 60%。
掌机只有一个马达，PS5 的左右两个震动通道会合并成一路。


六、串流参数建议
--------------------------------------------
默认：720p / 30fps / 8Mbps / H.264
- 画面卡顿：按 R1 进设置，降到 540p 或把码率调到 6000
- 画面糊：码率往上加（局域网可以到 20000）
- 1080p 很吃力（软件解码），除非网络和机器都很好，否则不建议
串流时画面上下黑边会显示实时状态：帧率、每帧转换耗时、网络 RTT


七、已知限制
--------------------------------------------
1. 纯软件解码，1080p/60 帧吃力，推荐 720p
2. 不支持 PSN 打洞，公网必须自己做端口映射
3. 同一时间只能串流一台 PS5
4. 触屏/触摸板是按键模拟（单击 START），不是真触摸


八、常见问题
--------------------------------------------
Q: 列表里没有主机？
A: 确认掌机和 PS5 在同一 WiFi；或按 Y 手动填 IP；PS5 要开机并
   在「设置 → 系统 → 远程游玩」里启用远程游玩。

Q: 连接时提示「Remote is already in use」？
A: PS5 上还有上一个会话没释放，等 1 分钟，或按 L1 唤醒一次再试。

Q: 连上了但黑屏 / 没画面？
A: 九成是 UDP 没通。检查路由器是否映射了 UDP 9296（不只是 TCP）。

Q: 卡死 / 画面闪烁？
A: 不要用 SSH 后台启动本程序，必须从 Apps 菜单启动（否则会和
   主界面抢屏幕）。
